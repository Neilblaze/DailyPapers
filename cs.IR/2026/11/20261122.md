### Bridging Blind Spots With Words: Decentralized Multi-View Spatial Reasoning via Language-Constrained Communication
- **Arxiv ID**: http://arxiv.org/abs/2611.29112v1
- **DOI**: None
- **Categories**: **cs.CV**, cs.AI, cs.IR, cs.LG
- **Links**: [PDF](https://arxiv.org/pdf/2611.29112v1)
- **Published**: 2026-11-22 00:23:01+00:00
- **Updated**: 2026-11-22 00:23:01+00:00
- **Authors**: Soumyabrata Chaudhuri, Joydeep Ghosh
- **Comment**: 17 pages, 13 tables, 4 figures
- **Journal**: None
- **Summary**: As multimodal LLMs (MLLMs) get increasingly used as collaborative partners across embodied robotics, AR/VR, and multi-user systems, spatial reasoning is now often distributed across agents with partial environment visibility, necessitating spatial reasoning integration. Prior work in language-mediated spatial integration is however strictly limited to simplified two-agent scenarios. To address this gap, we first formalize the general problem of decentralized multi-view spatial reasoning, where N agents observe distinct viewpoints, exchange budget-constrained natural language messages, and collaborate to enable a listener to answer spatial queries. We then introduce a novel multi-view spatial benchmark to isolate queries that demand non-trivial multi-view integration. Through an extensive empirical study, we discover that the penalty of restricting decentralized spatial reasoning to natural language with limited budget is far smaller than suggested by prior two-agent literature. Nevertheless, we observe that substantial headroom still remains for multi-agent spatial reasoning in this setting, as evidenced by a significant gap between current centralized performance and an oracle best-of-K ceiling. Moreover, we show that reinforcement learning with credit assignment substantially bolsters the decentralized model, effectively closing the gap with the centralized baseline.



### DataRecycle: Trustworthy Distillation of Structured Data from Scattered Web Evidence
- **Arxiv ID**: http://arxiv.org/abs/2611.29206v1
- **DOI**: None
- **Categories**: **cs.HC**, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2611.29206v1)
- **Published**: 2026-11-22 04:06:48+00:00
- **Updated**: 2026-11-22 04:06:48+00:00
- **Authors**: Can Liu, Tengteng Zhu, Xinyu Jiang, Xiaolin Wen, Yong Wang
- **Comment**: None
- **Journal**: None
- **Summary**: The web contains vast amounts of scattered quantitative evidence that is difficult to organize into comparable and verifiable structures. Yet its unstructured, sparse, and sometimes conflicting nature makes a systematic distillation costly and error-prone. Existing approaches force users to make a trade-off: search engines return document lists that require labor-intensive extraction and reconciliation, while generative AI systems produce fluent summaries that obscure data provenance, introduce reporting bias, and hide inconsistencies. We present DataRecycle, an interactive system that helps transform scattered web evidence into structured tables of comparable numerical facts. Given a user's query or statement, DataRecycle decomposes it into entities and attributes, retrieves candidate evidence, and organizes scattered, potentially conflicting records in a table-based evidence view. To address key challenges in automated data distillation (i.e., incomplete retrieval, untraceable generation, sparse data distribution, and multi-source inconsistency), DataRecycle adopts an ontology-guided, top-down data acquisition strategy, visualizes the recorded lineage from retrieved snippets to extracted values, and aligns heterogeneous data across dimensions such as time, definition, and scale. We evaluate DataRecycle through module-level experiments, a usage scenario, and a user study, showing that the system helps users organize numerical web evidence into provenance-linked tables and inspect uncertainty and conflicting sources.



### Zarc: Exact Nearest Neighbors over a Billion Vectors in Seconds
- **Arxiv ID**: http://arxiv.org/abs/2611.29252v1
- **DOI**: 10.5281/zenodo.23674583
- **Categories**: **cs.DC**, cs.DB, cs.IR, cs.LG
- **Links**: [PDF](https://arxiv.org/pdf/2611.29252v1)
- **Published**: 2026-11-22 05:45:22+00:00
- **Updated**: 2026-11-22 05:45:22+00:00
- **Authors**: Dongfang Zhao
- **Comment**: Identical to https://zenodo.org/records/23674584
- **Journal**: None
- **Summary**: Exact k-nearest-neighbor vector search lies on the critical path of machine learning systems, from sparse attention in the latest large language models (LLMs) to long-context memories and training-data deduplication. Exhaustive GPU search scans the whole dataset for every query, while approximate indexes return inexact neighbors. Recent methods skip almost every vector with a cheap half-precision proof that it lies too far away, but only on one GPU that holds the whole dataset. Our insight is to keep only the short rows of these proofs in GPU memory and to fetch the few remaining full vectors from host memory. Our system, Zarc, answers Euclidean, cosine, inner-product, and filtered queries exactly under updates. On four H100 GPUs, it answers 10,000 exact queries over one billion vectors in 1.1 seconds instead of five minutes. On eleven open LLMs, it retrieves the exact top-10 attention keys 2.2x to 13.1x faster than exhaustive search. In sparse attention over one million tokens, it runs 3.1x faster than bf16 selection with FlashInfer, which misses the exact top-64 for most queries.



### NoeVera: Can Knowledge Guide Experiments and Experiments Refine Knowledge?
- **Arxiv ID**: http://arxiv.org/abs/2611.29255v1
- **DOI**: None
- **Categories**: **cs.AI**, cs.CL, cs.DC, cs.IR, cs.LG
- **Links**: [PDF](https://arxiv.org/pdf/2611.29255v1)
- **Published**: 2026-11-22 05:49:43+00:00
- **Updated**: 2026-11-22 05:49:43+00:00
- **Authors**: Pinaki Prasad Guha Neogi, Spyros Mastorakis, Ankur Mallick, Saravan Rajmohan, Victor Rühle
- **Comment**: 20 pages, 2 figures
- **Journal**: None
- **Summary**: With the growing demand for large language model (LLM) services, optimizing LLM serving systems is becoming increasingly complex, and the bottleneck is no longer predicting how a given configuration will perform. The harder problem is deciding what to investigate: which mechanisms matter for a workload, which configurations are worth testing, and what evidence a decision still needs. In this work, we present NoeVera, an agentic Second Brain that goes beyond just one-shot retrieval by turning papers, code, benchmarks, and experimental results into a persistent, provenance-preserving knowledge base with three planes: source evidence, reusable synthesis, and agent memory. Decision-aware retrieval assembles compact evidence packs, role-specific agents reason over them and invoke a simulator (Vidur or GAUSS) whenever quantitative support is needed, and every finding is written back as a scoped evidence record, so knowledge guides experiments and experiments refine knowledge. In configuration search over four serving scenarios, NoeVera comes within 5% of the optimum in a median of 6-7 simulator calls, versus 9 for Bayesian optimization and 15 for a knowledge-free agent with the same tools; on A100 GPUs, its representative configurations deliver ~1.30x vLLM-default throughput and meet every scenario's latency objective. When reused, provenance-preserving evidence records over-generalize on only 8% of applicability traps, versus 28% for a general-purpose agent memory. On the held-out 48-task split of a 72-task benchmark, NoeVera scores 29% higher than an equally equipped agent and 36% higher than its single-call retrieval counterpart (0.80 vs. 0.62 and 0.59), and even when baselines receive NoeVera's own prompts, a statistically significant part of its evidence-evolution advantage remains.



### LLM-Based Assistant for Dog Care Guidance
- **Arxiv ID**: http://arxiv.org/abs/2611.29286v1
- **DOI**: None
- **Categories**: **cs.CL**, cs.AI, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2611.29286v1)
- **Published**: 2026-11-22 07:19:38+00:00
- **Updated**: 2026-11-22 07:19:38+00:00
- **Authors**: Abubakar Sadiq Shittu, Venkat Gopu, Arshita Sharma, Jacob Kennedy
- **Comment**: None
- **Journal**: None
- **Summary**: This study investigates whether domain grounding through Retrieval-Augmented Generation (RAG) and parameter-efficient fine-tuning using Low-Rank Adaptation (LoRA) can enhance the accuracy and reliability of pet care advice generated by large language models (LLMs). We curated a dataset of breed-specific dog care information and used it to develop two systems: a RAG pipeline based on TinyLlama-1.1B-Chat-v1.0, and a fine-tuned LLaMA-3.2-1B model adapted using LoRA. Both systems were evaluated on 15 dog care questions. The RAG model achieved a perfect average score of 2.0, outperforming the fine-tuned model (mean = 1.47). Statistical analyses, including Welch's t-test, Mann-Whitney U, and Wilcoxon signed-rank tests (all p < 0.05), confirmed the significance of the performance gap. Our findings suggest that retrieval-based domain grounding leads to more accurate, consistent, and trustworthy responses than standalone fine-tuning in specialized LLM applications.



### VistaTree: Question Answering over Long Multimodal Documents with Image-Derived Summary Trees

- **Links**: [PDF](https://arxiv.org/pdf/2611.29419v1)
- **Published**: 2026-11-22 11:55:45+00:00
- **Updated**: 2026-11-22 11:55:45+00:00
- **Authors**: Yexiang Cheng, Xiaochen Zheng, David Tokar, Tatyana Y. Doktorova
- **Comment**: 11 pages, 3 figures, 6 tables
- **Journal**: None
- **Summary**: Answering questions over long multimodal documents requires locating relevant evidence across pages containing text, tables, and figures. When the document exceeds the model's context window, selective retrieval becomes necessary. We introduce VistaTree, a document question-answering agent that builds a summary tree directly from rendered page images. VistaTree segments documents into contiguous page spans, recursively groups them into a topic hierarchy, and refines sibling summaries to distinguish neighboring sections. At query time, the agent uses node summaries to select relevant nodes and reads the corresponding pages, using hierarchical navigation when the full outline exceeds the context budget. Experiments on MMLongBench-Doc and LongDocURL evaluate answer quality and retrieval cost using a locally hosted vision-language model, and quantify the performance gap between global and hierarchical access to the index.



### MoR4Rec: Mixture-of-Recursion for Sequential Recommendation
- **Arxiv ID**: http://arxiv.org/abs/2611.29462v1
- **DOI**: None
- **Categories**: **cs.IR**, cs.AI
- **Links**: [PDF](https://arxiv.org/pdf/2611.29462v1)
- **Published**: 2026-11-22 13:02:59+00:00
- **Updated**: 2026-11-22 13:02:59+00:00
- **Authors**: Tiwari Ankit Satyaprakash, Adamya Shyam, Vikas Kumar, Bharti Rana, Venkateswara Rao Kagita
- **Comment**: 22 pages, 5 figures
- **Journal**: None
- **Summary**: Sequential recommender systems aim to predict a user's next interaction by modeling temporal dependencies in historical behavior sequences. To capture such dependencies, recent approaches increasingly rely on attention-based architectures, particularly transformers. While effective at modeling long-range sequential patterns, these models apply a fixed computation depth to all interaction items, treating them as equally complex. However, user behavior is inherently heterogeneous, with many interactions following simple repetitive patterns, whereas others require modeling higher-order dependencies. This mismatch leads to inefficient utilization of model capacity and unnecessary computational overhead, particularly in deep transformer-based architectures. To address this issue, we propose MoR4Rec, a sequential recommendation framework based on a Mixture-of-Recursion paradigm, which enables item-wise adaptive computation through a shared transformer backbone. A learned routing mechanism dynamically assigns each item to an appropriate recursion depth, allocating deeper computation to complex interactions while processing simpler patterns more efficiently. To improve computational efficiency, we develop a cascade-based strategy with key-value sharing across recursion steps. We further introduce a gated attention mechanism that adaptively regulates contextual information during recursive sequence modeling. Extensive experiments on three benchmark datasets show that MoR4Rec consistently outperforms strong transformer-based baselines, achieving average gains of 2.28% in Recall@5, 2.50% in NDCG@5, and 2.0% in MRR@5 over the strongest baseline. The improvements remain consistent across top-10 and top-20 recommendation cutoffs, while comparisons with vanilla transformers demonstrate the computational efficiency of adaptive recursive processing.



### Weight Coding: Evolving Web-Scale Recommenders through Direct Weight Edits with LLM Agents
- **Arxiv ID**: http://arxiv.org/abs/2611.29613v1
- **DOI**: None
- **Categories**: **cs.IR**, cs.AI, cs.LG
- **Links**: [PDF](https://arxiv.org/pdf/2611.29613v1)
- **Published**: 2026-11-22 17:11:38+00:00
- **Updated**: 2026-11-22 17:11:38+00:00
- **Authors**: Junpeng Hou, Jiaxing Qu, Derek Cheng, Jaewon Yang, Abhinav Naikawadi, Karthik Subbian
- **Comment**: None
- **Journal**: None
- **Summary**: Web-scale recommender models evolve primarily through retraining or fine-tuning. We propose \emph{weight coding}, a methodology for model evolution through direct, executable weight edits. A large language model (LLM) agent inspects model structure and parameters, formulates hypotheses, and implements edits using evaluation feedback. The loop progresses from localized changes to targeted searches and composition, allowing edited components to adapt to one another. A cached engine enables rapid forward evaluation without backpropagation. On Pinterest's 147M-parameter Image Search two-tower retriever, weight coding improves held-out recall@10 of production model by up to 15.0 percentage points (+24\% relative) with few edits in about 1/4 GPU hours of a full post-training finetune, while a common launch only improves around 1\%. After reinitializing the entire 13.6M-parameter interaction module randomly while retaining the surrounding trained model, searching 2,448 mixing and normalization parameters yields 9.8 points above production. Offline gains span the full funnel including dense retrieval, generative retrieval and ranking, with up to 1.37B learnable parameters and different edits for each architecture. Steering edits provide explicit control of model performance over segments like freshness and product. Weight coding requires no serving change and online A/B tests increase saves per user from the edited retrieval source by 8.4\% to 10.7\%, aligned with the target business objectives. Our results establish weight coding as a practical and useful tool for model development and and behavioral control in a real web-scale production system, with potential to extend to both pre-training and post-training stages across the funnel.



### Where Do Fact-Checking Errors Arise? Separating Retrieval, Search Control and Judgement in Evidence-Grounded Verification
- **Arxiv ID**: http://arxiv.org/abs/2611.29697v1
- **DOI**: None
- **Categories**: **cs.CL**, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2611.29697v1)
- **Published**: 2026-11-22 18:58:15+00:00
- **Updated**: 2026-11-22 18:58:15+00:00
- **Authors**: Martin Pavlíček, Martin Kotyrba, Eva Volná, Tomáš Filip, Petr Sosík
- **Comment**: None
- **Journal**: None
- **Summary**: An evidence-grounded fact-checker can fail because it does not find the evidence or because it does not use it; end-to-end accuracy does not tell the two apart. We present a protocol that follows the reference evidence from the store to the verdict and separates retrieval, search control, judgement and verdict validation. We assess 293 claims from FEVER, FEVER 2.0 and AVeriTeC with one open-weights 9B model under two evidence conditions: small stores of annotated evidence, where discovery is easy, and the full source collections. In the control condition a single hybrid retrieval pass delivers complete reference evidence for 226 of 228 evidence-bearing claims, and adaptive controllers and a tool agent spend two to nine times as many model calls without a consistent gain. Of 34 decisive claims labelled as lacking evidence, 33 have the complete evidence in the packet: in 15 the judge abstains, and in 18 validation rules overturn a decisive verdict. On AVeriTeC these rules lower single-pass accuracy by six points, to 65.0% (balanced accuracy 57.6%). Ten judges from eight model families also show abstentions and validation conversions on fixed packets. Against the full stores hybrid single-pass accuracy falls by 17 to 29 points. Wikipedia evidence recovery declines; AVeriTeC recovery changes from annotated answers to cited pages and is measured separately. No controller recovers the accuracy loss. The agent also shows no resolved gain on 714 further Wikipedia claims. Evidence recovery, judgement and validation should be measured separately before an error is attributed to search.
