### Structure-Aligned History Learning with Subspace-Structured Semantic IDs for Generative Recommendation
- **Arxiv ID**: http://arxiv.org/abs/2610.25093v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.25093v1)
- **Published**: 2026-10-18 07:58:35+00:00
- **Updated**: 2026-10-18 07:58:35+00:00
- **Authors**: Kaiwen Wei, Kejun He, Jie Zhang, Xiaomian Kang, Yuming Yang, Aijia Zhou, Xie Zhou, Yining Wang, Nayu Liu, Li Jin, Zhenyang Li, Jiang Zhong, He Bai, Jingxuan Wei, Junnan Zhu
- **Comment**: 34 pages, 10 figures, including references and appendices
- **Journal**: None
- **Summary**: Generative recommendation constructs semantic IDs for catalog items and predicts the next ID from user interaction histories. However, existing methods face limitations in both stages. First, conventional quantizers may produce imbalanced code assignments and lack coherent intermediate semantic units between individual tokens and complete items, limiting history reconstruction. Second, recommendation models remain dominated by next-item prediction, treating historical interactions mainly as conditioning context and providing limited supervision for recovering persistent preferences across the historical path, particularly when relevant preference signals are distributed over distant interactions. To address these limitations, Structure-Aligned History Learning (SAHL) reconnects the two stages by using the structure created during quantization directly for history reconstruction. Its Semantic Residual Balanced Quantization (SRBQ) forms a balanced token-subspace-item hierarchy, and SAHL reconstructs history at these same granularities. Predictive entropy prioritizes uncertain transitions, while curriculum optimization progressively shifts training to inference-aligned next-item prediction. On four Amazon Review categories, SAHL improves NDCG@10 by 18.6%-30.0% over RPG and 2.7%-6.0% over strong method MHL. Controlled analyses verify balanced code use, the benefit of following quantizer-defined groups during reconstruction, and dependence on user history. The relevant code is available at https://github.com/CQU-MM-Intelligent-Lab/SAHL.



### Toward Agentic Retrieval-Augmented Generation for Enterprise Retail Workflows over Heterogeneous Data Sources
- **Arxiv ID**: http://arxiv.org/abs/2610.25096v1
- **DOI**: None
- **Categories**: **cs.AI**, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2610.25096v1)
- **Published**: 2026-10-18 08:15:12+00:00
- **Updated**: 2026-10-18 08:15:12+00:00
- **Authors**: Jeonghwan Choi, Jibin Hwang, Hayoon Park, Hyeonjae Cheon, Hwanjun Song
- **Comment**: Preprint. Under review
- **Journal**: None
- **Summary**: Enterprise retail workflows require agents to chain evidence across heterogeneous sources, from structured product and order records to unstructured inquiries and reviews, yet existing agentic RAG benchmarks rarely capture this challenge. To enable controlled evaluation of such workflows, we introduce RetailBridge, a compositional retail benchmark built from persona-driven simulations. Its questions are constructed by linking entities and intermediate answers across heterogeneous sources, requiring agents to identify the relevant sources, carry evidence between them, and produce a grounded answer. To systematically evaluate LLMs on these retail workflows, we develop RetailRAG, a retail-aware framework equipped with auto-schema briefing, source-routed plan chaining, and diagnostic plan revision. RetailRAG consistently outperforms existing agentic RAG baselines across all evaluation axes, serving as a strong reference system for assessing LLM agents on retail workflows. On RetailBridge, evaluating ten LLM backbones with RetailRAG reveals multi-source chaining as the dominant bottleneck across providers and model scales, suggesting that reliable retail agents require explicit cross-source orchestration rather than scaling alone. Code and data are publicly available at \url{https://github.com/DISL-Lab/RetailBridge}.



### RemoteANN: A Native Vector Search Engine for Cloud Object Storage
- **Arxiv ID**: http://arxiv.org/abs/2610.25172v1
- **DOI**: None
- **Categories**: **cs.DB**, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2610.25172v1)
- **Published**: 2026-10-18 10:52:39+00:00
- **Updated**: 2026-10-18 10:52:39+00:00
- **Authors**: Yutong Gou, Silu Huang, Yue Wang, Jianjun Chen, Cheng Long
- **Comment**: None
- **Journal**: None
- **Summary**: Vector search engines built on cloud object storage have drawn growing attention from both academia and industry. These systems typically adopt a disaggregated storage-compute architecture, persisting the primary vector payload in object stores (e.g., Amazon S3) while retaining compact index metadata on compute nodes. However, conventional vector indexing structures are not natively tailored to the pronounced network latency and per-request access costs of cloud object stores, resulting in network I/O amplification, degraded query throughput, and higher API expenses.   To resolve these challenges, we present RemoteANN, a vector search engine explicitly co-designed for cloud object storage across indexing and querying. To mitigate the dominant network I/O bottleneck, RemoteANN couples an Inverted File (IVF) index with RaBitQ quantization, further optimized by inter-cluster and intra-cluster data reordering for improved data locality. Building on this tailored data layout, RemoteANN's query engine combines cluster pruning, fine-grained Range-GET requests, request merging, and local NVMe SSD caching, dramatically reducing discrete storage requests and network transfer volume without sacrificing accuracy. To address the index construction bottleneck, we further develop QGKMeans, which substantially reduces construction latency without compromising clustering quality. Extensive evaluations on real-world datasets demonstrate that, compared with representative baselines, RemoteANN achieves up to a $5.9\times$ throughput speedup while issuing up to $16.1\times$ fewer object storage requests at 97% target recall.



### When Semantics Fall Short: Persona-Guided Cross-Domain Sequential Recommendation with Large Language Models
- **Arxiv ID**: http://arxiv.org/abs/2610.25221v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.25221v1)
- **Published**: 2026-10-18 12:28:23+00:00
- **Updated**: 2026-10-18 12:28:23+00:00
- **Authors**: Jundong Chen, Honglei Zhang, Shuai An, Enneng Yang, Han Yu
- **Comment**: None
- **Journal**: None
- **Summary**: Cross-domain sequential recommendation (CDSR) alleviates data sparsity by transferring user behaviors across domains. Recent advances increasingly leverage large language models (LLMs) to bridge domains through global item semantics. However, this paradigm is inherently limited by two issues: I. semantic domain isolation, where item semantics remain domain-specific and hinder transferable modeling, and II. semantic-behavior inconsistency, where local semantic relations are more consistent with behavioral transitions, whereas such consistency often breaks down globally across domains. To this end, we propose PerCDR, an LLM-enhanced CDSR framework that shifts the focus from global semantic bridging to persona-guided behavioral modeling. Specifically, PerCDR leverages LLM-inferred personas to globally guide transferable cross-domain behavioral patterns, while exploiting local semantic relations to enhance intra-domain behavioral modeling, followed by domain preference adaptation for recommendation refinement. Extensive experiments demonstrate the superiority of PerCDR and validate its effectiveness.



### Bridging Concepts: Multi-Agent Reasoning over Scientific Concept Graphs for High-Impact Research Prediction
- **Arxiv ID**: http://arxiv.org/abs/2610.25281v1
- **DOI**: None
- **Categories**: **cs.AI**, cs.IR, cs.LG
- **Links**: [PDF](https://arxiv.org/pdf/2610.25281v1)
- **Published**: 2026-10-18 13:56:40+00:00
- **Updated**: 2026-10-18 13:56:40+00:00
- **Authors**: Donggyu Yoon, Minsung Hwang, Juneha Baek, Donghyuk Shin, Joyce Jiyoung Whang
- **Comment**: 5 pages, 2 figures, 4 tables, The 3rd Workshop on Knowledge-Enhanced Information Retrieval (KEIR) at The 35th ACM International Conference on Information and Knowledge Management (CIKM 2026)
- **Journal**: None
- **Summary**: Within a research community, new topics often emerge when previously unconnected concepts are first studied together. We construct scientific concept graphs (SCGs)--domain knowledge graphs whose nodes are fine-grained research concepts extracted from paper text by LLMs and whose edges capture their co-occurrence in papers--and study the task of forecasting high-impact concept pairs, i.e., discovering concept pairs that are currently unconnected but will have high impact when connected. To this end, we introduce new benchmark datasets constructed from CIKM, KDD, and SIGIR conference papers, with varied prediction settings, including impact forecasting for emerging concepts unseen during training. We propose MiroGraph, a Multi-agent reasoning framework with scientific concept Graphs, in which a feature designer agent designs predictive features for a given concept pair from structural, semantic, and trend perspectives, and then three LLM agents compute the actual feature values from the enclosing subgraph of the concept pair. Using these feature values, a classifier designer agent constructs a classifier that predicts the final impact labels. MiroGraph outperforms various impact forecasting and temporal link prediction methods.



### MEMORA: A Memory-Enhanced Multimodal Committee Reranking Agent for Reasoning-Intensive Retrieval
- **Arxiv ID**: http://arxiv.org/abs/2610.25282v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.25282v1)
- **Published**: 2026-10-18 14:00:10+00:00
- **Updated**: 2026-10-18 14:00:10+00:00
- **Authors**: Mohamed Mahmoud, Mostafa Farouk Senussi, Mahmoud Abdalla, Mahmoud SalahEldin Kasem, Abdelrahman Abdallah, Hyun Soo Kang
- **Comment**: Accepted at EMNLP Main 2026
- **Journal**: None
- **Summary**: Reasoning-intensive retrieval is fundamentally challenged when queries demand deep semantic inference and arrive in multimodal form. Existing systems treat each query in isolation, rely on monolithic rerankers, and lack retrievers trained for cross-modal reasoning. We introduce MEMORA, a Memory-Enhanced Multimodal Orchestrated Reranking Agent built around three contributions: (1) Collaborative Factor-Committee Reranking, which decomposes queries into intent factors, extracts factor-specific evidence into a structured matrix, and synthesizes judgments via a memory-conditioned meta-verdict model; (2) an Episodic Memory Module that tracks factor outcomes across queries and dynamically adjusts priorities at inference time; and (3) a Reasoning-Aware Dense Retriever fine-tuned with chain-of-thought augmentation on 20k+ reasoning-intensive pairs. Evaluated on MM-BRIGHT across 29 domains, MEMORA achieves nDCG@10 of 41.5 (text-to-text) and 38.9 (multimodal query-to-text), outperforming the strongest agentic text-only baseline by +8.3 points and the strongest agentic multimodal baseline by +7.9 points. Code and data are available at https://github.com/HarnessLab/MEMORA.



### Where and Why Search-Augmented LLMs Fail When Reasoning over Rapidly Evolving Knowledge
- **Arxiv ID**: http://arxiv.org/abs/2610.25323v1
- **DOI**: None
- **Categories**: **cs.CL**, cs.AI, cs.IR, cs.LG
- **Links**: [PDF](https://arxiv.org/pdf/2610.25323v1)
- **Published**: 2026-10-18 15:09:08+00:00
- **Updated**: 2026-10-18 15:09:08+00:00
- **Authors**: Tianyi Hu, Bhavyajeet Singh, Niket Tandon, Akhil Arora
- **Comment**: None
- **Journal**: None
- **Summary**: As the world changes, new information is published while older records remain online. This complicates reasoning for large language models (LLMs), which must retrieve evidence and resolve conflicts to determine which information remains valid. Existing evaluations treat information seeking as a black box, revealing little about where and why LLMs fail. To address this gap, we introduce TREK, a suite of three components: TREKTRACE is a plug-and-play framework that attributes failures to specific stages of retrieval and reasoning. We apply it to TREKBENCH-WILD, a meta-benchmark of real-world questions that require complex reasoning over rapidly evolving knowledge. Surprisingly, the main bottleneck is post-retrieval reasoning rather than retrieval: frontier models are often misled by conflicting evidence even after retrieving all the information needed to answer. To study this bottleneck, we build TREKBENCH-CTRL, a controlled benchmark with distractors spanning temporality, relevance, and trustworthiness, and show that benchmarks dominated by outdated distractors substantially underestimate task difficulty. Together, TREK provides a testbed for diagnosing and improving reasoning over rapidly evolving knowledge.



### Whistle and Wrong Lyrics: Synthetic Queries Are Not Enough for Real-World Query-by-Melody
- **Arxiv ID**: http://arxiv.org/abs/2610.25371v1
- **DOI**: None
- **Categories**: **cs.SD**, cs.IR, cs.LG
- **Links**: [PDF](https://arxiv.org/pdf/2610.25371v1)
- **Published**: 2026-10-18 16:17:03+00:00
- **Updated**: 2026-10-18 16:17:03+00:00
- **Authors**: Luigi Rivolta
- **Comment**: 15 pages, 2 figures, 6 tables. Code: https://github.com/luiginotmario/hum2song
- **Journal**: None
- **Summary**: People look up a song by humming it, but also by whistling it or singing it with the wrong words. Published query-by-humming systems and benchmarks focus on hums and sung queries, and no public dataset pairs whistles or wrong-lyrics singing with song recordings. We study both query types with a melody-only retrieval system: a key-normalized pitch track embedded by a 5.2M-parameter contour encoder, with a spectral-peak tracker for whistles. First, a physics-grounded generator renders synthetic whistles and nonsense-syllable singing from the vocal melodies of 11,083 songs. Training on them raises top-1 retrieval of held-out synthetic queries against an 11,050-song gallery from 0.180 to 0.251 for whistles and from 0.193 to 0.264 for wrong-lyrics singing, but the gain does not transfer: on the MLEnd test performers the best synthetic-only model gets 210 of 339 real whistles right at top-1, against 214 for the baseline. Second, a closed-set fine-tune on real MLEnd whistles with performer-disjoint splits raises whistle-to-hum top-1 from 0.631 (95% CI 0.581-0.681) to 0.673 (0.622-0.723), on known songs only. Third, two further generations of synthetic queries also fail to transfer: melody-conditioned whistles and la-la singing from a commercial neural music model leave real-whistle top-1 at 0.631, and an open-source pipeline (YingMusic-Singer-Plus singing with partly wrong, mumbled or nonsense lyrics, a DDSP whistle synthesizer, and a melody-error model fitted on real performers) gives at best 0.619 (paired difference -0.012, 95% CI -0.038 to +0.015). Across physics-based, commercial neural and open-source neural synthetic data, nothing transferred to real whistles, which points to collecting real queries as the missing step. Code is public; models and data will be released.



### MemDerive: A Diagnostic Benchmark for Agent Memory over Evolving Data
- **Arxiv ID**: http://arxiv.org/abs/2610.25373v1
- **DOI**: None
- **Categories**: **cs.DB**, cs.AI, cs.CL, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2610.25373v1)
- **Published**: 2026-10-18 16:24:33+00:00
- **Updated**: 2026-10-18 16:24:33+00:00
- **Authors**: Sen Gao, Yongan Li, Han Chen, Bingsheng He, Ming Wu, Jason Zeng, Michael Heinrich, Shixuan Sun
- **Comment**: None
- **Journal**: None
- **Summary**: Long-running agents rely on memory of their past interactions for task state, such as what has been completed and which conditions still hold. Such state is usually a derived state. No record states it, and it must be computed by rules from multiple records of an evolving history. Existing memory benchmarks score only the final answer, with no reference for the intermediate states behind it. A wrong answer therefore cannot be traced to the state that was missed, and a state that silently became outdated goes undetected. We present MemDerive, a diagnostic benchmark for agent memory over evolving data. It specifies each scenario symbolically, derives exact gold answers with Datalog, records the gold derivation DAG and the supporting events of every query, and renders the history in natural language with fictional entities and distractors. Its 10 scenarios contain 4,692 events and 1,503 queries whose difficulty varies along access, evolution, and composition. On this ground truth, MemDerive evaluates answer reliability, diagnoses failures by probing the nodes of the gold derivation DAG, and tracks whether answers stay correct as events arrive. Our evaluation of four memory systems reveals failures that final-answer benchmarks hide. On derived state, every memory system falls behind simple BM25 retrieval, although the same answer model reaches 96.01% when given the supporting events. Most failures are ungathered, as a system holds the missing intermediate state but does not retrieve it for the question that needs it. Memory systems also rarely propagate implicit changes, which no new record states. These results suggest three principles for memory design. Gather inputs along the derivation, store rules with their versions, and maintain derived states through recorded dependencies.



### Weakly Supervised Adaptation of Scientific Embeddings for Exploratory Literature Mapping
- **Arxiv ID**: http://arxiv.org/abs/2610.25413v1
- **DOI**: None
- **Categories**: **cs.DL**, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2610.25413v1)
- **Published**: 2026-10-18 17:09:48+00:00
- **Updated**: 2026-10-18 17:09:48+00:00
- **Authors**: Roman Neruda, Petra Vidnerová, Jiří Šejnoha, Jakub Mihálik, Tomáš Marvan
- **Comment**: None
- **Journal**: None
- **Summary**: Scientific document embeddings such as SPECTER2 are optimized for retrieval over large, heterogeneous corpora. On a small specialized corpus their similarity distributions can become highly compressed, which limits their usefulness for exploratory literature mapping. We study whether weakly supervised in-domain adaptation, using only metadata already available in open citation databases, changes this geometry. On ArtCon, a curated corpus of 704 publications on artificial and machine consciousness, we adapt the SPECTER2 proximity model with a lightweight LoRA adapter trained on positive pairs derived from bibliographic coupling in OpenAlex, using no manually annotated similarity labels. We compare the adapted embeddings with lexical (TF-IDF), citation-based (bibliographic coupling) and generic semantic (SPECTER2) representations under thresholded, fixed-density and symmetric k-nearest-neighbour graph constructions. Adaptation substantially decompresses the similarity distribution (mean pairwise cosine similarity 0.9104 to 0.8663, standard deviation 0.0259 to 0.0594) and yields graphs with markedly higher Louvain modularity and better connectivity than the base encoder under matched edge and neighbourhood budgets. The effect is stable across all three graph constructions and is therefore not an artefact of a single sparsification choice. We report this as a case study on one corpus, and we are explicit about what it does not establish: the clustering indices used here are computed against community labels derived from each representation's own similarity graph, so they measure internal geometric self-consistency rather than agreement with an external topical ground truth, and adaptation and evaluation use the same documents. Evaluation against independent labels, on held-out documents, and against geometric controls is ongoing work.



### Selling in the Wild: Benchmark and Randomized Field Evidence for a Sales Agent Trained on Commercial Conversations
- **Arxiv ID**: http://arxiv.org/abs/2610.25461v1
- **DOI**: None
- **Categories**: **cs.IR**, cs.CY
- **Links**: [PDF](https://arxiv.org/pdf/2610.25461v1)
- **Published**: 2026-10-18 18:45:04+00:00
- **Updated**: 2026-10-18 18:45:04+00:00
- **Authors**: Benjamin Tannenbaum
- **Comment**: None
- **Journal**: None
- **Summary**: We test whether Javo, a sales agent fine-tuned on 4.6 million consented, de-identified commercial conversations, sells better than a frontier general-purpose model and better than human sales associates. The evaluation has four parts. Study 1 scores the agent on two public sales benchmarks, SalesLLM and SmartSalesBench, against 10 frontier and open-weight models. Study 2 is a randomized controlled trial on 100 live websites in 14 industries (e-commerce, travel and hospitality, and high-consideration services), run from 1 May to 30 September 2026, in which 14.8 million visitors were randomized to no agent, Javo, or a frontier-model agent with an identical interface, catalog tools and guardrails. Study 3 isolates the effect of the model by comparing those two agent arms. Study 4 compares Javo with each site's own human associates on 20 sites with staffed live chat. Relative to no agent, Javo changed revenue per visitor by +10.0% (95% CI +5.1 to +14.9). Among engaged visitors, it changed conversion by +21.6% relative to the frontier-model agent (95% CI +16.9 to +26.3). Against human associates, its engaged conversion was 11.26% versus 11.20% (non-inferior, margin -7%, one-sided p = 0.004; no significant superiority), at 1.8% of the cost per conversation. Return rates, unsupported product claims and complaint rates met the prespecified safety guardrails.



### Benchmark for Structured Retrieval-Augmented Generation in Perovskite Photovoltaics
- **Arxiv ID**: http://arxiv.org/abs/2610.25575v1
- **DOI**: None
- **Categories**: **cs.LG**, cs.AI, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2610.25575v1)
- **Published**: 2026-10-18 22:37:23+00:00
- **Updated**: 2026-10-18 22:37:23+00:00
- **Authors**: Qiwei Han, Chi Zhou, Gaoxiang Yuan
- **Comment**: 8 pages, 3 figures, 2 tables
- **Journal**: None
- **Summary**: While retrieval-augmented language models increasingly serve as literature assistants in the physical sciences, existing benchmarks evaluate them primarily on qualitative text overlap or through model-based scoring rather than against verified experimental ground truth. In experimental materials disciplines such as perovskite photovoltaics, however, the most critical inquiries are inherently quantitative and aggregate measurements across dozens or hundreds of papers. Here, we present a quantitative question-answering benchmark where all 755 ground-truth answers are computed directly from 45,441 measured device records (40,889 human-curated records through 2021 and 4,552 records extracted from 2022-2026 literature). Benchmarking six retrieval architectures over 158,274 passages from 25,662 papers using an open 14B model on a single 24 GB GPU, standard passage retrieval tops out at 16-23% accuracy (compared to 1.6-6.5% zero-shot). In contrast, equipping the language model with read-only SQL execution over the structured device table elevates accuracy to 51.5% on historical and 50.8% on prospective literature -- a 33.01.8 percentage-point advantage over hybrid text retrieval. Aggregate queries spanning extrema, distributions, and filtered record counts prove virtually unsolvable via text retrieval alone, demonstrating that systematic table extraction is an operational prerequisite for literature-scale quantitative inquiry.
