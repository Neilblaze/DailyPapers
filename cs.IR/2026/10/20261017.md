### Optimal Fusion Weights Form Intervals, Not Points: A Latency-Aware Study of Query-Adaptive WRRF
- **Arxiv ID**: http://arxiv.org/abs/2610.24341v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.24341v1)
- **Published**: 2026-10-17 00:18:41+00:00
- **Updated**: 2026-10-17 00:18:41+00:00
- **Authors**: Iris Ma, Zahra Shekarchi, Stuart Mcilroy, Mahtab Farrokh, Fattane Zarrinkalam, Joel Stremmel
- **Comment**: None
- **Journal**: None
- **Summary**: Reciprocal Rank Fusion (RRF) is widely used to combine sparse and dense retrievers in hybrid information retrieval, but a critical limitation is that it assigns a fixed, uniform weight to each retriever regardless of the query. Query-aware methods treat the per-query optimal weight as a single point, an assumption whose empirical validity has not been examined. We present an empirical study of eight dynamic fusion weight prediction strategies across four datasets and four sparse--dense retriever pairs. When we compare these approaches to static fusion and a per-query oracle that bounds achievable performance, several findings emerge. First, the per-query optimal fusion weight is typically an interval rather than a point. Queries can have multiple optimal intervals, and these can take on a variety of shapes. Second, 74 of 128 dynamic fusion methods tested were significantly better than standard RRF after false discovery rate correction. Third, dynamic fusion methods exhibit differing quality and latency characteristics that should be considered when choosing an appropriate fusion method. To address this last finding, we present a tiered decision framework that maps practitioner constraints, dataset properties, label availability, hardware, and latency budget to an appropriate method class. We release the code for our experiments at https://github.com/thomsonreuters/query-based-rrf.



### DuoLM: Fast and Effective Personalized Recommendation with Language Models
- **Arxiv ID**: http://arxiv.org/abs/2610.24481v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.24481v1)
- **Published**: 2026-10-17 05:56:40+00:00
- **Updated**: 2026-10-17 05:56:40+00:00
- **Authors**: Jiang Wu, Yutong Song, Hongbo Wang, Guanghe Cao, Jeff Liang
- **Comment**: 19 pages. Jiang Wu and Yutong Song contributed equally
- **Journal**: None
- **Summary**: Language models can make personalized recommendations from rich item content, user history, and feedback. However, evaluating many candidates with full-text inputs incurs substantial online computation and limits serving throughput. We introduce DuoLM, a framework for fast and effective personalized recommendation that integrates a compact recommendation model with an efficient serving runtime. An encoder LLM learns compact item representations for offline reuse, while a personalized ranker LLM combines them with user history and feedback for recommendation. We train both models end to end with recommendation supervision and teacher distillation. The runtime further accelerates inference through virtual token IDs for embedding access, shared history computation, and CUDA Graph replay. Benchmark results show that our framework achieves recommendation quality comparable to that of the expert teacher model. On a single H100, it delivers approximately 26,400 candidate scores per second, about $60\times$ the throughput of the teacher served with vLLM and automatic prefix caching.



### RAGit: Turning Document Preprocessing into an Experimental Variable for RAG
- **Arxiv ID**: http://arxiv.org/abs/2610.24659v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.24659v1)
- **Published**: 2026-10-17 12:17:02+00:00
- **Updated**: 2026-10-17 12:17:02+00:00
- **Authors**: Omar El Bachyr, Saad Ezzini, Tegawendé F. Bissyandé, Jacques Klein
- **Comment**: 4 pages, 2 figures, 4 tables. Accepted at the Tool Demonstration Track of the 33rd Asia-Pacific Software Engineering Conference (APSEC 2026)
- **Journal**: None
- **Summary**: Document preprocessing choices can substantially affect retrieval in Retrieval-Augmented Generation (RAG) pipelines, yet they are often selected heuristically and are difficult to compare under consistent conditions. We present RAGit, an open-source experimentation workbench for the systematic and reproducible evaluation of document preprocessing choices through downstream retrieval. RAGit represents parsing, chunking, indexing, retrieval, and evaluation as configurable experimental stages, enabling controlled comparisons while the remaining downstream settings are kept fixed. It preserves provenance from retrieved chunks to source pages and maps heterogeneous retrieval units to a common page-level ranking for evaluation. The current implementation supports multiple parsers and chunking strategies, dense and late-interaction retrieval, reusable intermediate artifacts, and multi-configuration benchmarking. We demonstrate RAGit through controlled experiments comparing alternative preprocessing configurations under a fixed retrieval setup, illustrating how preprocessing can be treated as an explicit experimental variable. RAGit and its documentation are publicly available on GitHub (https://github.com/OmarElbachyr/ragit). A demonstration video is available at https://youtu.be/tsst-Bhfz4I.



### MemRevise: A Self-Revising Memory for Conversational Search
- **Arxiv ID**: http://arxiv.org/abs/2610.24672v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.24672v1)
- **Published**: 2026-10-17 12:48:53+00:00
- **Updated**: 2026-10-17 12:48:53+00:00
- **Authors**: Mohammed Ali, Abdelrahman Abdallah, Adam Jatowt
- **Comment**: None
- **Journal**: None
- **Summary**: In conversational search, users correct misun-derstandings, revise their requests and return to earlier topics, so part of the history no longer reflects what they want. Existing benchmarks do not isolate such turns. Current search methods either re-read the history or keep a record of every turn, and none of them marks earlier content as dropped. We introduce CONVREVISE, a benchmark of 4,429 test questions in six tiers of returns and revisions over TopiOCQA, CORAL and OR-QuAC. We also propose MEMREVISE, which combines a revisable memory graph, a 3B writer distilled from teacher memories, and a search guided by the memory. The writer reads each turn once and adds a node that records its topic, its facts and the operations it performs, such as adding, abandoning or reactivating a topic. Topic status follows from these operations, so a dropped topic keeps its facts and can be restored. With a frozen retriever, MEMREVISE reaches a mean MRR@10 of 0.701, against 0.589 for the best competitor, ConvSearch-R1-FT, and 0.617 for a writer distilled the same way without the memory, so the memory and the steps built on it add 0.084. MEMREVISE is significantly better on Topi- OCQA and OR-QuAC, statistically tied with prompted 32B rewriters on CORAL, and never significantly behind the strongest competitor of any tier.



### VisR-RAG-Fin: Benchmarking Multimodal RAG over Visually Rich Financial Documents
- **Arxiv ID**: http://arxiv.org/abs/2610.24822v1
- **DOI**: None
- **Categories**: **cs.IR**
- **Links**: [PDF](https://arxiv.org/pdf/2610.24822v1)
- **Published**: 2026-10-17 19:11:26+00:00
- **Updated**: 2026-10-17 19:11:26+00:00
- **Authors**: Omar El Bachyr, Laura Maria Bernardy, Saad Ezzini, Jacques Klein, Tegawendé F. Bissyandé, Charles Mont'e, Anas Zilali, Ulrick Ble, Anne Goujon
- **Comment**: Accepted at the main research track of ACM SIGIR-AP 2026, Singapore, December 13-15, 2026
- **Journal**: None
- **Summary**: Enterprise documents such as financial reports are increasingly processed by automated systems, yet they are primarily designed for human reading and exhibit complex visual structure, combining dense text with tables, charts, diagrams, and rich layouts. These characteristics pose significant challenges for Retrieval-Augmented Generation (RAG) systems, which must retrieve relevant pages and leverage visual and structural information during answer generation. Despite recent advances in multimodal retrieval and vision-language models, there remains a limited understanding of how design choices across retrieval and generation components affect end-to-end RAG performance on visually rich documents. In this paper, we present a comprehensive empirical study of multimodal RAG for page-level Question Answering (QA) over financial documents. We introduce VisR-RAG-Fin (Visually Rich RAG for Finance), an open-source benchmark constructed through a general pipeline for visually rich documents that preserves original layout and visual content. Using this benchmark, we systematically analyze retrieval and generation behavior under text-only, multimodal, and hybrid configurations, providing a foundation for rigorous evaluation of RAG systems on complex enterprise document collections. Overall, this work provides actionable insights for practitioners designing and evaluating multimodal RAG pipelines over complex, visually rich enterprise documents.



### Learning to Program Retrievals: Composing Search Primitives via Reinforcement Learning
- **Arxiv ID**: http://arxiv.org/abs/2610.24854v1
- **DOI**: None
- **Categories**: **cs.CL**, cs.IR
- **Links**: [PDF](https://arxiv.org/pdf/2610.24854v1)
- **Published**: 2026-10-17 20:03:09+00:00
- **Updated**: 2026-10-17 20:03:09+00:00
- **Authors**: Kyuyoung Kim, Zilin Xiao, Zhiyuan Wang, Avinash Atreya, Ke Yang, Jinwoo Shin, Kecheng Hao
- **Comment**: None
- **Journal**: None
- **Summary**: Retrieval-augmented language models increasingly use multi-step search to solve knowledge-intensive tasks, yet existing systems typically expose retrieval through fixed pipelines or collections of atomic tools. We introduce Retrieval Program Learning (RPL), a programmable search framework that allows a policy to compose search primitives into executable programs with local state and control flow. This enables adaptive search that can retrieve broadly, process intermediate results, and selectively construct model context without tying retrieval breadth to context consumption. However, the resulting flexibility creates a difficult exploration problem: useful programs may require several coordinated decisions, while reinforcement learning often supplies only sparse feedback. To address this challenge, we propose program mutation, a grammar-constrained and execution-verified procedure that generates local variants of suboptimal programs sampled during RL, converts them into training trajectories, and distills them back into the policy. We evaluate RPL on open-domain question answering and corpus-level reasoning tasks, comparing it with a range of retrieval and reasoning baselines. RPL consistently improves open-domain QA performance across model sizes and in- and out-of-domain benchmarks, with particularly large gains on multi-hop tasks. Notably, a 4B model trained with RPL outperforms all 8B model baselines. On corpus-level reasoning, RPL achieves the highest answer F1 and document-coverage F1 for both model sizes while substantially reducing context consumption and retrieval turns. Our results show that programmable search expands the retrieval strategies that agents can learn, while program mutation provides an effective mechanism for exploring useful program structures beyond direct on-policy sampling.
